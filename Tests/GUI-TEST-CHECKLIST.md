# GUI test checklist

Проверять на Windows 11, сначала обычный запуск, затем отдельный запуск приложения «от имени администратора».

## 1. Библиотеки

1. Открыть «Библиотеки».
2. Проверить установленный компонент: статус «Установлено».
3. Нажать «Удалить», подтвердить.
4. После завершения карточка должна сразу стать «Не установлено».
5. Переключить окно/вернуться на страницу и убедиться, что статус остаётся корректным.
6. Для ручного компонента проверить статус «Ручная установка».
7. При появлении состояния обновления проверить «Доступно обновление».
8. Проверить автоматическую установку с заведомо неуспешным установщиком: ненулевой код не должен считаться успехом.

## 2. Windows Settings

1. Открыть настройки без администратора и проверить блокировку только системных параметров.
2. Для UAC проверить «никогда не уведомлять». На системе с ранее выключенным UAC выключение этого режима не должно самовольно включать UAC.
3. Для SmartScreen выключить и снова включить параметр, затем сверить фактическое состояние Windows.
4. Для прямых записей реестра проверить, что при ошибке записи UI сообщает об ошибке, а не «сохранено».
5. Проверить включение/выключение Home в Проводнике и повторное открытие страницы.

## 3. Мышь

1. Перемещать ползунок скорости — он должен двигаться плавно, без зависаний и без самопроизвольного возврата.
2. Остановить ползунок на произвольном значении и убедиться, что применяется именно последнее значение после короткой паузы.
3. Перемещать ползунок строк прокрутки — он должен быть таким же плавным, как скорость указателя.
4. Нажать «По умолчанию» у скорости — значение должно стать 10 и сохраниться в Windows.
5. Нажать «По умолчанию» у прокрутки — значение должно стать 5 и сохраниться в Windows.
6. Переключить ускорение и проверить фактическое состояние Windows.
7. Закрыть/открыть страницу и сверить все значения с Windows.

## 4. Recent apps и иконки

1. Открыть приложение с Главной и вернуться на Главную — оно должно попасть в recent.
2. Быстро несколько раз открыть Главную и изменить ширину окна — список не должен дублироваться или прыгать.
3. Проверить одно приложение на Главной и в Программах — иконка должна определяться одинаково.
4. Старые записи recent по имени должны продолжать читаться; новые должны сохраняться по стабильному ID.

## 5. Загрузки

1. Проверить название кнопки «Очистить историю загрузок».
2. Нажать её: история должна очиститься, а сами скачанные файлы остаться.
3. Нажать Delete на отдельной записи: запись и соответствующий файл должны удалиться.
4. Выбрать перемещённую системную папку Загрузки в Windows и проверить, что каталог по умолчанию совпадает с системным Known Folder.
5. Перезапустить приложение после операций с историей и убедиться, что история остаётся читаемой.

## 6. UWP

1. Открыть «UWP приложения» и дождаться списка.
2. Удалить приложение, установленное для текущего пользователя.
3. Проверить удаление приложения из всех пользователей/provisioned, если такое есть.
4. После удаления список должен повторно проверить фактическое состояние.
5. При недоступности всех способов перечисления приложение должно показать ошибку, а не трактовать пустой список как нормальное состояние.

## 7. Проводник

1. Нажать «Перезапустить Проводник».
2. Убедиться, что explorer.exe реально завершился и снова запустился.
3. Проверить панель задач, рабочий стол и открытие папок после перезапуска — Проводник не должен оставаться сломанным.

## 8. Версия

1. В интерфейсе проверить версию 1.1.0.
2. В свойствах EXE проверить File version 1.1.0.0.

## 9. Не изменять в этом прогоне

Не считать изменёнными: administrative logic Game Mode/PowerShell, stderr PowerShell, HAGS detection, Windows Update/hosts, namespace/gallery ownership, runtime-image temporary files, WallpaperService.forceRefresh и прочие пункты, отмеченные «не трогать».

## 10. Диалоги подтверждения

1. Открыть удаление UWP-приложения или другой операции с подтверждением.
2. Проверить порядок кнопок: «Да» слева, «Нет» справа.
3. Проверить, что «Да» выполняет действие, а «Нет»/закрытие отменяют его.

## 11. Активация Windows

1. Открыть «Активация Windows» и нажать HWID-активацию.
2. Не должно открываться окно редактора или видимое окно .cmd.
3. Должен запускаться существующий `Scripts\\HWID_Activation.cmd` с параметром HWID и скрытым процессом.
4. После выполнения проверить фактический статус активации Windows.
5. При повторном запуске уже активированной Windows не должно появляться ложной ошибки из-за проверки CRLF скрипта.
