# WpfApp1

Приложение на WPF .NET 8 для управления каталогом приложений, библиотек и диагностикой окружения.

## Возможности

- Обновление и просмотр каталогов приложений
- Работа с локальными данными в формате JSON
- Поддержка диагностики каталога и проверки окружения
- Интерфейс на WPF

## Требования

- Windows 10/11
- .NET 8 SDK
- Visual Studio 2022 или другой поддерживаемый IDE для WPF

## Запуск

1. Откройте решение `WpfApp1.slnx` в Visual Studio.
2. Соберите проект.
3. Запустите приложение.

## Сборка

```bash
dotnet build WpfApp1.csproj
```

## Примечание

Проект содержит локальные данные и ресурсы, которые могут копироваться в выходную папку во время сборки.
